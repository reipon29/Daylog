# Daylog

X（旧Twitter）のようにつぶやく感覚で書ける、自分専用の日記 PWA。
ほぼ日手帳のような「1日1ページ」に、その日のヘルスケアと行った場所の地図がまとまります。

## 機能

- **ホーム**: X風のタイムライン。テキスト・写真（4枚まで）・位置情報つきでポスト。`#タグ` 検索、お気に入り、編集、共有
- **チェックイン**: 文章なしで「いまいる場所」だけを記録
- **写真から足あと**: 写真に記録された撮影場所・日時を読み取り、その時間・場所で記録。日記帳の「写真から追加」で複数枚まとめて追加できる
- **日記帳**: 1日1ページ。からだ（ヘルスケア）／足あと（地図と経路）／できごと／過去の同じ日
- **カレンダー**: 月表示。書いた日・位置つきの日・歩数がひと目でわかる
- **足あと**: これまで行った場所を全部地図に表示（30日／1年／全期間）
- **バックアップ**: JSON で書き出し・読み込み。2週間バックアップしていないとホームでお知らせ
- オフライン動作、ホーム画面に追加してアプリとして使用可能

データはすべて**端末内（IndexedDB）**に保存され、サーバーには送られません。
例外として「地名を調べる」が ON のとき、座標が OpenStreetMap（Nominatim）に送られます（設定で OFF にできます）。

## 公開（GitHub Pages）

ビルド不要です。リポジトリをそのまま公開するだけで動きます。

```sh
git remote add origin git@github.com:<ユーザー名>/daylog.git
git push -u origin main
```

GitHub のリポジトリ → **Settings → Pages → Build and deployment**
→ Source: `Deploy from a branch` / Branch: `main` `/ (root)` を選んで保存。

数分後に `https://<ユーザー名>.github.io/daylog/` で公開されます。
iPhone の Safari で開き、**共有 → ホーム画面に追加** でアプリになります。

> 位置情報・クリップボードは HTTPS でのみ動きます（GitHub Pages は HTTPS なので OK）。

### ローカルで試す

```sh
python3 -m http.server 8000
# → http://localhost:8000
```

### 更新を配信するとき

`sw.js` の `VERSION`（例: `daylog-v1` → `daylog-v2`）を上げてから push してください。
アプリは次回起動時に新しいファイルを取り込みます。

## ヘルスケア連携

Web アプリ（PWA）は iPhone のヘルスケアを直接読むことができません。
そこで **iOS の「ショートカット」アプリ**で今日の値をまとめてコピーし、Daylog に取り込む方式にしています。

### ショートカットの作り方

1. 「ショートカット」アプリ → 「＋」で新規作成。名前は「Daylog ヘルス」など
2. 項目ごとに次のアクションを追加
   - `ヘルスケアサンプルを検索`（種類: **歩数**、開始日: **今日**）
   - `統計を計算`（**合計**）
   - 距離・アクティブエネルギー・エクササイズ時間も同様（合計）
   - 安静時心拍数・体重は `並び順: 最新` `上限: 1` で取得
   - 睡眠は種類: **睡眠分析**、開始日: **過去1日以内**、値: **睡眠中**（コア/深い/レム）→ 各サンプルの `継続時間` を合計
3. `日付を書式設定`（現在の日付 / カスタム `yyyy-MM-dd`）
4. `辞書` を追加し、以下のキーに値を割り当て
5. `クリップボードにコピー`（辞書をそのまま渡す）
6. （任意）**オートメーション → 時刻 → 毎日 22:00 → すぐに実行** にすると毎晩自動でコピー

その後 Daylog を開き、**日記帳の「取り込む」**または**設定 → クリップボードから取り込む** を押します。

### 取り込める形式

```json
{
  "date": "2026-11-06",
  "steps": 8123,
  "distance": 5.4,
  "activeEnergy": 320,
  "exercise": 35,
  "flights": 6,
  "sleep": 7.2,
  "restingHR": 58,
  "heartRate": 72,
  "weight": 62.5,
  "mindful": 10
}
```

- 必要な項目だけで OK。値は `"8,123 歩"` のような単位付き文字列でも読み取ります
- 日本語キー（`歩数` `距離` `睡眠` `体重` など）でも可
- 睡眠は時間／分／秒、距離は km／m を自動判定
- 複数日まとめて渡すときは配列 `[{...}, {...}]` または `{"days": [...]}`
- `date` を省略すると今日の日付になります

## 位置情報について

PWA は**アプリを開いているときだけ**位置を取得できます（バックグラウンドで常時追跡はできません）。
そのため「足あと」は、位置つきのポスト・チェックイン・写真の撮影場所から作られます。

- チェックインし忘れても、夜に**日記帳 →「写真から追加」**でその日の写真を選べば足あとになります
- 同じ写真を2回選んでも二重には追加されません
- iPhone の写真選択画面では、設定によって**位置情報が外されて渡される**ことがあります。その場合は撮影日時だけが使われます
- 電波が悪くて地名が付かなかった場所は、次にオンラインになったとき自動で地名を調べ直します
- 地名の問い合わせは OpenStreetMap の利用規約に合わせて 1 秒に 1 回までに抑えています

## セキュリティ

- 外部から読み込む地図ライブラリには改ざん検知（SRI）を付けています。配信元で書き換えられた場合は読み込まれません
- `.gitignore` でバックアップファイル（`daylog-backup-*.json`）をコミットしないようにしています。バックアップはリポジトリのフォルダに置かないでください

## 構成

```
index.html            画面の骨組み
manifest.webmanifest  PWA 設定
sw.js                 オフライン用 Service Worker
css/style.css         スタイル（ライト/ダーク対応）
js/app.js             画面・ルーティング
js/db.js              IndexedDB（ポスト / 写真 / ヘルスケア）
js/health.js          ヘルスケア JSON の読み取り
js/location.js        現在地・地名変換（1秒1回の順番待ち）
js/exif.js            写真の撮影日時・場所の読み取り
js/util.js            共通関数
icons/                アプリアイコン
```

地図は [MapLibre GL JS](https://maplibre.org/) と [OpenFreeMap](https://openfreemap.org/)（© [OpenMapTiles](https://openmaptiles.org/) © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors）を使用しています。ベクター地図なので高解像度の画面でもくっきり表示され、APIキーも不要です。
